# 더불어민주당 울산시당 교육연수원 홈페이지 기획 및 화면 설계안

본 문서는 `01_울산시당_교육연수원_운영계획.md`의 내용을 기반으로, 실제 웹사이트(반응형 웹 애플리케이션)로 구현하기 위한 **정보 구조(IA), 사이트맵, 화면 레이아웃 및 핵심 기능 명세**를 정의합니다.

---

## 1. 홈페이지 개발 개요

* **사이트명**: 더불어민주당 울산광역시당 교육연수원 (가칭: `민주울산 AI 에듀 플랫폼`)
* **목적**:
  1. 민주당의 역사·정통성 및 울산 맞춤 정책 교육의 상시 디지털 제공
  2. 전국 최초 전 당원 맞춤형 AI 리터러시 교육 프로그램 신청 및 학습 지원
  3. 정책 브리프, 교육 영상, 강의 자료의 체계적 디지털 아카이빙
  4. '울산 민주 크리에이터 100인' 산출물 전시 및 온·오프라인 당원 소통 활성화
* **주요 타겟**: 울산시당 권리당원, 일반당원, 시니어 당원, 청년·여성 정치지망생, 일반 시민

## 3. 페이지별 상세 기획 및 와이어프레임 구조

### (1) 메인 페이지 (Main Landing Page)
* **Hero 섹션 (비주얼 배너)**:
  - 메인 카피: *"깨어있는 당원, 실력 있는 민주당, 승리하는 울산시당"*
  - 서브 카피: *"전국 시·도당 최초! 민주주의 정통성과 AI 디지털 역량을 겸비한 스마트 교육 플랫폼"*
  - CTA 버튼: [AI 교육 수강신청 바로가기] / [이달의 정책브리프 읽기]
* **핵심 가치 카드 (4대 운영목표)**:
  - 당원 주권 확립 / AI 리터러시 구축 / 정책 역량 강화 / 실전 캠페이너 배출
* **AI 혁신 과정 퀵 네비게이터**:
  - 1주차(왕초보 입문) ~ 4주차(고급 실전) 단계별 요약 및 즉시 신청 카드
* **최신 소식 & 정책 브리프 하이라이트**:
  - 격주 발행되는 울산 시정 현안 분석 보고서 최신호 노출
* **크리에이터 명예의 전당 (Shorts & 카드뉴스 캐러셀)**:
  - 당원들이 AI로 제작한 인기 숏폼 영상 및 카드뉴스 갤러리
* **연간/월간 교육 캘린더 위젯**:
  - 이번 달 예정된 교육 일정 한눈에 보기

### (2) AI 혁신 아카데미 (전 당원 맞춤형 교육)
* **레벨 진단 테스트**:
  - 당원이 본인의 스마트폰/PC 활용 수준을 3문항으로 체크 후 적합 과정(입문~실전) 자동 추천
* **주차별 상세 커리큘럼 탭**:
  - 1단계(왕초보): 스마트폰 AI 앱 설치, 뉴스 3줄 요약
  - 2단계(기초): 프롬프트 엔지니어링, 정책 질의응답
  - 3단계(중급): 정책 칼럼, 이미지 포스터, 카드뉴스 제작
  - 4단계(실전): 숏폼 영상, 선거 스토리텔링, 팩트체크
* **원클릭 수강 신청 시스템**:
  - 이름, 소속 지역위원회, 전화번호, 희망 과정 선택 후 신청 접수

### (3) 정책 브리프 & 디지털 아카이브
* **카테고리 필터**: 전체 / 시정 개혁과제 / 산업·일자리(수소·해상풍력) / 민생·골목상권 / 자치분권
* **문서 뷰어**: 브라우저 내에서 PDF를 다운로드 없이 즉시 볼 수 있는 내장 뷰어 제공
* **마이크로러닝 영상 플레이어**:
  - 5~10분 분량의 유튜브 영상 임베드 및 강의록 첨부

### (4) 민주 크리에이터 100인 갤러리
* **탭 구성**: [전체] / [카드뉴스·포스터] / [숏폼·릴스] / [우수작 선정작]
* **작품 카드 인터랙션**:
  - 썸네일 클릭 시 상세 팝업 (제작자, 사용한 AI 도구, 제작 취지 설명)
  - '응원해요(좋아요)' 버튼 및 댓글 피드백 기능
  - SNS 공유 버튼 (카카오톡, 페이스북, X 등)

## 4. UI/UX 디자인 가이드라인

* **컬러 팔레트**:
  - **Primary**: 민주 블루 `#004EA2` (정통성과 신뢰의 브랜드 컬러)
  - **Secondary**: 스마트 시안 `#00A3E0` (AI 및 미래 혁신을 상징)
  - **Accent**: 활력 옐로우 `#FFCC00` (희망과 승리를 상징하는 강조색)
  - **Background**: 라이트 그레이 `#F8F9FA` & 순백색 `#FFFFFF`
* **타이포그래피**:
  - 기본 폰트: `Pretendard`, `Noto Sans KR` (가독성 높은 모던 고딕체)
  - 시니어 당원을 위한 **'글자 크기 확대(큰 글씨 모드)' 토글 버튼** 헤더 배치
* **반응형 웹 최적화**:
  - 모바일 접근율이 70% 이상인 당원 특성을 고려하여 Mobile-First 레이아웃 적용

## 5. 권장 기술 스택 (구현 방안)

* **Frontend**: Next.js 14 (App Router) + Tailwind CSS + Lucide Icons + Framer Motion
* **Backend / Database**: Supabase (PostgreSQL, 인증, 파일 스토리지) 또는 Next.js API Routes
* **호스팅**: Vercel 또는 Cloudflare Pages (빠른 로딩 및 안정성)

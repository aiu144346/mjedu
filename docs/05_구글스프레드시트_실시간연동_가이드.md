# 울산시당 교육연수원 AI 교육 사전신청 - 구글 스프레드시트 실시간 연동 가이드

본 가이드는 홈페이지의 **[AI 교육과정 사전신청서]** 모달에서 당원이 작성한 신청 내역이 **울산시당 구글 스프레드시트로 실시간 자동 저장**되도록 연동하는 3분 완성 안내서입니다.

---

## 📌 하이브리드 연동 시스템의 핵심 장점
1. **당원 경험 극대화**: 웹사이트를 벗어나지 않고 세련된 화면에서 원클릭으로 신청 완료
2. **실무자 편의성 100%**: 당직자/원장님이 스마트폰이나 PC에서 구글 시트를 열면 신청자(성명, 연락처, 지역위, 희망과정)가 실시간으로 자동 기입되어 있어 바로 단체 문자 및 전화 안내 가능
3. **완전 무료 & 유지보수 불필요**: 별도의 유료 데이터베이스나 서버 관리 없이 구글 공식 무료 인프라 활용
4. **오프라인/카톡 병행**: 인쇄용 포스터나 단톡방 공유용 QR코드 및 단축 URL 동시 지원

---

## 🚀 3분 완성 연동 절차

### 1단계: 구글 스프레드시트 생성
1. [구글 드라이브(drive.google.com)](https://drive.google.com)에 로그인 후 **[+ 새로 만들기] ➔ [Google 스프레드시트]**를 생성합니다.
2. 스프레드시트 파일 제목을 다음과 같이 입력합니다:  
   `[울산시당] AI 교육과정 사전신청자 명단`
3. 시트의 **1행(A1 ~ G1)**에 아래와 같이 열 제목(헤더)을 입력합니다:
   - `A1`: **접수일시**
   - `B1`: **성명**
   - `C1`: **연락처**
   - `D1`: **이메일**
   - `E1`: **소속지역위원회**
   - `F1`: **희망교육과정 (복수선택)**
   - `G1`: **비고 및 건의사항**

---

### 2단계: Apps Script 붙여넣기 및 웹 앱 배포
1. 구글 시트 상단 메뉴에서 **[확장 프로그램] ➔ [Apps Script]**를 클릭합니다.
2. 기존 편집기에 적혀있는 기본 코드를 모두 지우고, 프로젝트 폴더 내 **[`google-apps-script.js`](../google-apps-script.js)** 파일의 전체 내용을 그대로 복사하여 붙여넣습니다.
3. 상단 **[저장(💾 또는 Ctrl+S)]** 버튼을 누릅니다.
4. 우측 상단 파란색 **[배포] ➔ [새 배포]** 버튼을 클릭합니다.
5. 좌측 톱니바퀴 아이콘(유형 선택)을 눌러 **[웹 앱(Web App)]**을 선택합니다.
   - **설명**: `울산시당 AI 사전신청 수신`
   - **다음 사용자로 실행**: `나(내 이메일)`
   - **액세스 권한이 있는 사용자**: **`모든 사용자 (Anyone)`** ★반드시 선택★
6. **[배포]**를 누르고, 권한 검토 팝업이 뜨면 계정 선택 ➔ `고급` ➔ `(안전하지 않음)으로 이동` ➔ `허용`을 클릭합니다.
7. 배포가 완료되면 화면에 나타나는 **"웹 앱 URL"**을 복사합니다.
   - 예시 형태: `https://script.google.com/macros/s/AKfycbx.../exec`

---

### 3단계: 홈페이지 `js/main.js`에 URL 입력
1. 홈페이지의 **[`js/main.js`](../js/main.js)** 파일을 엽니다.
2. 상단 10번째 줄 부근의 `GOOGLE_SHEET_WEBAPP_URL` 변수에 복사한 웹 앱 URL을 붙여넣습니다:
   ```javascript
   const GOOGLE_SHEET_WEBAPP_URL = "https://script.google.com/macros/s/발급받은_URL/exec";
   ```
3. 저장하면 **즉시 실시간 연동이 가동**됩니다!

---

## 📱 카카오톡 및 포스터용 QR코드 활용법
* 홈페이지 사전신청 모달 창 하단에 있는 **[📱 모바일 신청 QR코드 보기]** 버튼을 누르면 스마트폰으로 스캔 가능한 대형 QR코드가 팝업됩니다.
* 이 QR코드를 캡처하거나 다운로드하여 울산시당 교육 홍보 웹포스터, 현수막, 카카오톡 단체방 공지에 첨부하시면 스마트폰에서도 바로 사전 신청이 가능합니다.
